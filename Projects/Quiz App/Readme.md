# Quiz App

A simple quiz application built with HTML, CSS, and JavaScript.

## Features

- **Multiple Choice Questions:** Answer multiple choice questions.
- **Score Calculation:** Calculate the score based on correct answers.
- **Undo Answer:** Undo the last selected answer.
- **Customizable Number of Questions:** Choose the number of questions to answer.
- **Responsive Design:** Works well on different screen sizes.

## How to Use

1. Open the `index.html` file in your web browser.
2. Enter the number of questions you want to solve in the setup section.
3. Click the "Start Quiz" button.
4. Answer the multiple choice questions by clicking on the options.
5. Click the "Submit" button to submit your answer.
6. Click the "Undo" button to undo the last selected answer.
7. View your score at the end of the quiz.
8. Click the "Play Again" button to restart the quiz.
