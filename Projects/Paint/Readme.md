# Paint App

A simple paint application built with HTML, CSS, and JavaScript.

## Features

- **Pen:** Draw freehand lines.
- **Eraser:** Erase existing drawings.
- **Rectangle:** Draw rectangles.
- **Circle:** Draw circles.
- **Clear:** Clear the entire canvas.
- **Color Picker:** Choose a color for drawing.
- **Save:** Save the drawing as a PNG image.
- **Dark/Light Mode:** Toggle between dark and light themes.

## How to Use

1. Open the `index.html` file in your web browser.
2. Select a tool from the toolbar (Pen, Eraser, Rectangle, Circle).
3. Choose a color from the color picker.
4. Draw on the canvas using your mouse.
5. Click the "Save" button to save your drawing.
6. Click the "Toggle Dark/Light Mode" button to switch between themes.
